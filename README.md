# KARV — Tattoo Studio Challenge

Landing page da seleção artística KARV, implementada a partir do Figma aprovado.

## Desenvolvimento

```bash
npm install
npm run dev
npm run build
```

Copie `.env.example` para `.env` e configure `PUBLIC_FORM_ENDPOINT` quando o destino oficial das inscrições for definido.

## Fonte visual

[Figma aprovado](https://www.figma.com/design/UUD6UXuRrjCykMbRQPzAjj)
